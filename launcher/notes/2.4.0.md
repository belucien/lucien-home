• Maintenance: every other Monday at 12:00 AM, Lucien Home tidies itself up: removes old update files, clears web caches (you stay signed in), tidies old alerts, refreshes both apps and checks for a new version.
• If nobody is using the PC, it then restarts fresh in the tray and installs any waiting update. If you're using it, that waits until you step away.
• See it under Settings › Maintenance, with Run now and a list of recent runs.
